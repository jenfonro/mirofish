# Miku 皮肤角色图（可选）

WebUI 的 Miku 皮肤不依赖这些图片：缺图时只应用配色，图片加载失败会自动隐藏。
把透明背景 PNG 按下列文件名放进本目录，然后重新执行 `cd webui && npm run build`
（Vite 会把 `public/` 原样拷进 `mirofish/static/`，relay 挂载为 `/miku/*`）。

| 文件名 | 用途 | 建议尺寸 | 构图 |
| --- | --- | --- | --- |
| `logo.png` | 顶栏标题左侧的小头像 | 256×256 | 头像/半身，居中，四周留少量空白 |
| `gate.png` | 登录页卡片左侧的立绘 | 高 ≥ 1000px，竖构图 | 全身站立，脚贴画面底边 |
| `mascot.png` | 主界面右下角看板娘 | 约 600×600 | Q 版全身（坐姿/挥手/探头），贴画面底边 |
| `favicon.png` | 浏览器标签页图标 | 64×64 | 可直接缩小 `logo.png` |
| `bg.jpg` | 主界面（已连接）整页淡背景 | 1920×1080 | 完整场景插画，无需透明；以 13% 不透明度平铺 |

要求：PNG 真透明通道（非白底/纯色底），角色完整不裁切。
如果生成器不支持透明输出，用纯绿/纯品红底生成后再抠图。
统一风格提示词见仓库根目录讨论或自行保持一致（teal twin-tails, clean lineart, cel shading）。
